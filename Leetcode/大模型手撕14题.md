## 1. P4489 Self-Attention 机制 `中等`

**原理**：每个 token 生成 Q/K/V，Q 与所有 K 点积得相关性，缩放 $\sqrt{d}$ 防 softmax 饱和，归一化后对 V 加权求和。

**公式**：

$$\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^{\top}}{\sqrt{d}}\right)V$$

```python
class Solution:
    def selfAttention(self, n: int, d: int, X: List[List[float]], Wq: List[List[float]], Wk: List[List[float]], Wv: List[List[float]]) -> List[List[str]]:
        X = torch.tensor(X, dtype=torch.float64)
        Wq = torch.tensor(Wq, dtype=torch.float64)
        Wk = torch.tensor(Wk, dtype=torch.float64)
        Wv = torch.tensor(Wv, dtype=torch.float64)
        Q = X @ Wq
        K = X @ Wk
        V = X @ Wv
        S = (Q @ K.T) / math.sqrt(d)
        A = torch.softmax(S, dim=1)
        O = A @ V
        return [[f"{x:.4f}" for x in row] for row in O.tolist()]
```

## 2. P4496 多头注意力 `中等`

**原理**：把 $d$ 切成 $h$ 个头，各头在 $d_k=d/h$ 子空间独立做缩放点积注意力，拼接后经 $W_o$ 投影合并。

**公式**：

$$\mathrm{head}_i=\mathrm{Attention}(QW_i^{Q},KW_i^{K},VW_i^{V}),\qquad \mathrm{MHA}=\mathrm{Concat}(\mathrm{head}_1,\dots,\mathrm{head}_h)W^{O}$$

```python
class Solution:
    def multi_head_attention(
        self,
        X: List[List[float]],
        W_Q: List[List[float]],
        b_Q: List[float],
        W_K: List[List[float]],
        b_K: List[float],
        W_V: List[List[float]],
        b_V: List[float],
        h: int,
        W_O: List[List[float]],
        b_O: List[float],
    ) -> List[List[float]]:

        X = torch.tensor(X, dtype=torch.float64)
        W_Q = torch.tensor(W_Q, dtype=torch.float64)
        b_Q = torch.tensor(b_Q, dtype=torch.float64)
        W_K = torch.tensor(W_K, dtype=torch.float64)
        b_K = torch.tensor(b_K, dtype=torch.float64)
        W_V = torch.tensor(W_V, dtype=torch.float64)
        b_V = torch.tensor(b_V, dtype=torch.float64)
        W_O = torch.tensor(W_O, dtype=torch.float64)
        b_O = torch.tensor(b_O, dtype=torch.float64)

        T, d_model = X.shape
        d_k = d_model // h

        # 1. 线性变换
        Q = X @ W_Q + b_Q
        K = X @ W_K + b_K
        V = X @ W_V + b_V

        # 2. 拆分多头: (T, d_model) -> (h, T, d_k)
        Q_heads = Q.reshape(T, h, d_k).transpose(0, 1)
        K_heads = K.reshape(T, h, d_k).transpose(0, 1)
        V_heads = V.reshape(T, h, d_k).transpose(0, 1)

        # 3. Scaled Dot-Product Attention
        scores = (Q_heads @ K_heads.transpose(-2, -1)) / math.sqrt(d_k)

        # torch.softmax 内部已经做了数值稳定处理
        attn_weights = torch.softmax(scores, dim=-1)

        # 4. 每个 head 的输出
        H_heads = attn_weights @ V_heads

        # 5. 拼接 heads: (h, T, d_k) -> (T, d_model)
        H = H_heads.transpose(0, 1).reshape(T, d_model)

        # 6. 输出线性层
        O = H @ W_O + b_O

        return O.tolist()

```

## 3. P4497 分组查询注意力 `中等`

**原理**：Q 有 $h$ 个头、K/V 只有 $kv$ 个头，每个 KV 头被 $h/kv$ 个 Q 头共享（`repeat_interleave` 对齐）。KV cache 缩小 $h/kv$ 倍，精度损失很小。

**公式**：

$$\mathrm{head}_i=\mathrm{Attention}\!\left(Q_i,\,K_{\lfloor i/(h/kv)\rfloor},\,V_{\lfloor i/(h/kv)\rfloor}\right)$$

```python
class Solution:
    def groupedQueryAttention(self, n: int, d: int, h: int, kv: int, X: List[List[float]], Wq: List[List[float]], Wk: List[List[float]], Wv: List[List[float]], Wo: List[List[float]]) -> List[List[str]]:
        X, Wq, Wk, Wv, Wo = (torch.tensor(A, dtype=torch.float64) for A in (X, Wq, Wk, Wv, Wo))
        dk = d // h
        Q = (X @ Wq).view(n, h, dk).transpose(0, 1)                    # (h, n, dk)
        K = (X @ Wk).view(n, kv, dk).transpose(0, 1)                   # (kv, n, dk)
        V = (X @ Wv).view(n, kv, dk).transpose(0, 1)
        rep = h // kv
        K = K.repeat_interleave(rep, 0)                                # KV 头复制对齐 Q 头
        V = V.repeat_interleave(rep, 0)
        S = Q @ K.transpose(-1, -2) / math.sqrt(dk)
        A = torch.softmax(S, dim=-1)
        O = (A @ V).transpose(0, 1).reshape(n, d)
        return [[f"{x:.4f}" for x in row] for row in (O @ Wo).tolist()]
```

## 4. P4498 交叉注意力 `中等`

**原理**：Q 来自查询序列 $X$（decoder 侧），K/V 来自上下文 $C$（encoder 侧），其余与自注意力相同。

**公式**：

$$\mathrm{CrossAttn}(X,C)=\mathrm{softmax}\!\left(\frac{(XW^{Q})(CW^{K})^{\top}}{\sqrt{d}}\right)(CW^{V})$$

```python
class Solution:
    def crossAttention(self, n: int, m: int, d: int, X: List[List[float]], C: List[List[float]], Wq: List[List[float]], Wk: List[List[float]], Wv: List[List[float]], Wo: List[List[float]]) -> List[List[str]]:
        X, C, Wq, Wk, Wv, Wo = (torch.tensor(A, dtype=torch.float64) for A in (X, C, Wq, Wk, Wv, Wo))
        Q = X @ Wq                                                     # (n, d)
        K = C @ Wk                                                     # (m, d)
        V = C @ Wv
        S = (Q @ K.T) / math.sqrt(d)                                   # (n, m)
        A = torch.softmax(S, dim=1)
        O = A @ V
        return [[f"{x:.4f}" for x in row] for row in (O @ Wo).tolist()]
```

## 5. P4791 两层的带因果注意力的 decoder `困难`

**原理**：两层 decoder 堆叠，每层 = 因果多头自注意力 + 残差 + FFN(ReLU) + 残差。因果 mask 为下三角，位置 $i$ 只能看到 $\le i$ 的 token。

**公式**：

$$M_{ij}=\mathbb{1}[j\le i],\qquad x\leftarrow x+\mathrm{CausalMHA}(x),\quad x\leftarrow x+\mathrm{ReLU}(xU)V$$

```python
class Solution:
    def twoLayerCausalDecoder(self, n: int, d: int, h: int, df: int, X: List[List[float]],
            Wq1: List[List[float]], Wk1: List[List[float]], Wv1: List[List[float]], Wo1: List[List[float]], U1: List[List[float]], V1: List[List[float]],
            Wq2: List[List[float]], Wk2: List[List[float]], Wv2: List[List[float]], Wo2: List[List[float]], U2: List[List[float]], V2: List[List[float]]) -> List[List[str]]:
        mask = torch.tril(torch.ones(n, n, dtype=torch.bool))          # 因果 mask
        def layer(x, Wq, Wk, Wv, Wo, U, V):
            dk = d // h
            Q = (x @ Wq).view(n, h, dk).transpose(0, 1)
            K = (x @ Wk).view(n, h, dk).transpose(0, 1)
            VV = (x @ Wv).view(n, h, dk).transpose(0, 1)
            S = Q @ K.transpose(-1, -2) / math.sqrt(dk)
            S = S.masked_fill(~mask, float('-inf'))                    # 看不到未来
            a = (torch.softmax(S, dim=-1) @ VV).transpose(0, 1).reshape(n, d) @ Wo
            x = x + a                                                  # 残差
            x = x + (torch.relu(x @ U) @ V)                            # FFN + 残差
            return x
        x = torch.tensor(X, dtype=torch.float64)
        x = layer(x, *(torch.tensor(A, dtype=torch.float64) for A in (Wq1, Wk1, Wv1, Wo1, U1, V1)))
        x = layer(x, *(torch.tensor(A, dtype=torch.float64) for A in (Wq2, Wk2, Wv2, Wo2, U2, V2)))
        return [[f"{x:.4f}" for x in row] for row in x.tolist()]
```

## 6. P5135 CLIP 对比学习损失 `中等`

**原理**： batch 内 $n$ 对图文，特征 L2 归一化后算 $n\times n$ 余弦相似度矩阵（乘温度 $t$），对角线为正样本，两个方向交叉熵平均（对称 InfoNCE）。

**公式**：

$$s_{ij}=t\cdot I_i^{\top}T_j,\qquad \mathcal{L}=-\frac{1}{2n}\sum_i\left[\log\frac{e^{s_{ii}}}{\sum_j e^{s_{ij}}}+\log\frac{e^{s_{ii}}}{\sum_j e^{s_{ji}}}\right]$$

```python
class Solution:
    def clipLoss(self, n: int, d: int, t: float, I: List[List[float]], T: List[List[float]]) -> str:
        I = F.normalize(torch.tensor(I, dtype=torch.float64), dim=-1)
        T = F.normalize(torch.tensor(T, dtype=torch.float64), dim=-1)
        S = (I @ T.T) * t                                              # (n, n)，对角线为正对
        lab = torch.arange(n)
        loss = (F.cross_entropy(S, lab) + F.cross_entropy(S.T, lab)) / 2
        return f"{loss:.4f}"
```

## 7. P5136 MTP Loss `中等`

**原理**：Multi-Token Prediction：第 $i$ 个 head（0=主 head）预测第 $t+i+1$ 个 token，总损失为各深度交叉熵的平均，训练信号密度翻倍。

**公式**：

$$\mathcal{L}_{MTP}=\frac{1}{D+1}\sum_{i=0}^{D}\mathrm{CE}\!\left(\hat{y}^{(i)},\,y_{i+2:\,}\right)$$

```python
class Solution:
    def mtpLoss(self, n: int, V: int, logits: List[List[List[float]]], ids: List[int]) -> str:
        # logits[i]: 第 i 个 head 的预测，形状 (n-i-1, V)；ids 长度 n
        loss = 0.0
        for i, lg in enumerate(logits):
            lg = torch.tensor(lg, dtype=torch.float64)
            tgt = torch.tensor(ids[i + 1: i + 1 + lg.size(0)], dtype=torch.long)
            loss += F.cross_entropy(lg, tgt)
        return f"{loss / len(logits):.4f}"
```

## 8. P5137 NTK-aware RoPE `中等`

**原理**：RoPE 用位置角度旋转 Q/K，使点积只依赖相对位置；NTK-aware 插值按扩展倍数 $s$ 放大 base：$b'=b\cdot s^{d/(d-2)}$，平滑外推长上下文。

**公式**：

$$\theta_i=(b')^{-2i/d},\qquad q'=q\odot\cos(m\theta)+\mathrm{rot}(q)\odot\sin(m\theta)$$

其中 $\mathrm{rot}$ 为前后半交换取负。

```python
class Solution:
    def ntkAwareRoPE(self, n: int, d: int, base: float, s: float, Q: List[List[float]], K: List[List[float]]) -> List[List[str]]:
        if s > 1:
            base = base * s ** (d / (d - 2))                           # NTK-aware 放大 base
        inv = 1.0 / (base ** (torch.arange(0, d, 2, dtype=torch.float64) / d))
        ang = torch.outer(torch.arange(n, dtype=torch.float64), inv)   # (n, d/2)
        cos = torch.cat([ang.cos(), ang.cos()], -1)                    # (n, d)
        sin = torch.cat([ang.sin(), ang.sin()], -1)
        def rot(x):
            x1, x2 = x.chunk(2, dim=-1)
            return torch.cat([-x2, x1], -1)
        Q = torch.tensor(Q, dtype=torch.float64)
        K = torch.tensor(K, dtype=torch.float64)
        Qr = Q * cos + rot(Q) * sin
        Kr = K * cos + rot(K) * sin
        return [[f"{x:.4f}" for x in row] for row in torch.cat([Qr, Kr], 0).tolist()]                           # 上半 Q'，下半 K'
```

## 9. P5138 KL 散度 `中等`

**原理**：衡量分布 $P$ 相对 $Q$ 的差异，非对称；恒有 $D_{KL}\ge 0$，相等时为 0。

**公式**：

$$D_{KL}(P\,\|\,Q)=\sum_i p_i\log\frac{p_i}{q_i}$$

```python
class Solution:
    def klDivergence(self, n: int, p: List[float], q: List[float]) -> str:
        p = torch.tensor(p, dtype=torch.float64)
        q = torch.tensor(q, dtype=torch.float64)
        kl = (p * (p.log() - q.log())).sum()
        return f"{kl:.4f}"
```

## 10. P5139 Paged Attention `中等`

**原理**：vLLM 把 KV cache 切成固定大小 block，按 block_table 映射物理块；计算时先 gather 回完整 K/V 再做标准注意力，消除显存碎片。

**公式**：

$$K_{seq}=\mathrm{concat}[k\_cache[b_0],\dots]_{[:\,len]},\qquad o=\mathrm{softmax}\!\left(\frac{qK_{seq}^{\top}}{\sqrt{d}}\right)V_{seq}$$

```python
class Solution:
    def pagedAttention(self, h: int, d: int, bs: int, seq_len: int, q: List[List[float]], k_cache: List[List[List[float]]], v_cache: List[List[List[float]]], block_table: List[int]) -> List[List[str]]:
        # q: (h, d) 当前 token；k_cache/v_cache: (num_blocks, bs, h, d)
        q = torch.tensor(q, dtype=torch.float64)
        kc = torch.tensor(k_cache, dtype=torch.float64)
        vc = torch.tensor(v_cache, dtype=torch.float64)
        nb = (seq_len + bs - 1) // bs
        idx = torch.tensor(block_table[:nb], dtype=torch.long)
        K = kc[idx].reshape(-1, h, d)[:seq_len]                        # gather + 截断
        V = vc[idx].reshape(-1, h, d)[:seq_len]
        S = torch.einsum('hd,lhd->hl', q, K) / math.sqrt(d)
        O = torch.einsum('hl,lhd->hd', torch.softmax(S, dim=-1), V)
        return [[f"{x:.4f}" for x in row] for row in O.tolist()]
```

## 11. P5140 DPO Loss `中等`

**原理**：跳过奖励模型，直接用偏好对优化：拉高 chosen 相对 ref 的比值、压低 rejected 的比值，塞进 sigmoid 取负对数似然。输入为序列级 log 概率（token 求和）。

**公式**：

$$\mathcal{L}_{DPO}=-\mathbb{E}\left[\log\sigma\!\left(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)}-\beta\log\frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)\right]$$

```python
class Solution:
    def dpoLoss(self, beta: float, chosen_logp: List[float], rejected_logp: List[float], ref_chosen_logp: List[float], ref_rejected_logp: List[float]) -> str:
        pi = torch.tensor(chosen_logp, dtype=torch.float64) - torch.tensor(rejected_logp, dtype=torch.float64)
        ref = torch.tensor(ref_chosen_logp, dtype=torch.float64) - torch.tensor(ref_rejected_logp, dtype=torch.float64)
        loss = -F.logsigmoid(beta * (pi - ref)).mean()
        return f"{loss:.4f}"
```

## 12. P5145 RMSNorm `简单`

**原理**：LayerNorm 去掉中心化，只把特征缩放到单位均方根长度，更快且效果相当。

**公式**：

$$\mathrm{RMS}(x)=\sqrt{\tfrac{1}{d}\sum_i x_i^2+\epsilon},\qquad y=\frac{x}{\mathrm{RMS}(x)}\odot g$$

```python
class Solution:
    def rmsNorm(self, n: int, d: int, eps: float, X: List[List[float]], g: List[float]) -> List[List[str]]:
        X = torch.tensor(X, dtype=torch.float64)
        g = torch.tensor(g, dtype=torch.float64)
        rms = torch.sqrt(X.pow(2).mean(-1, keepdim=True) + eps)
        return [[f"{x:.4f}" for x in row] for row in (X / rms * g).tolist()]
```

## 13. P5146 SwiGLU FFN `中等`

**原理**：一路线性变换过 SiLU 当门，另一路当内容，逐元素相乘后投影回 $d$，门控增强表达能力。

**公式**：

$$\mathrm{SwiGLU}(X)=\big(\mathrm{SiLU}(XW_1)\odot XW_2\big)W_3$$

```python
class Solution:
    def swigluFFN(self, n: int, d: int, df: int, X: List[List[float]], W1: List[List[float]], W2: List[List[float]], W3: List[List[float]]) -> List[List[str]]:
        X, W1, W2, W3 = (torch.tensor(A, dtype=torch.float64) for A in (X, W1, W2, W3))
        O = (F.silu(X @ W1) * (X @ W2)) @ W3
        return [[f"{x:.4f}" for x in row] for row in O.tolist()]
```

## 14. P5147 GRPO Loss `中等`

**原理**：同一 prompt 采样 $G$ 个输出，用组内奖励均值/标准差归一化得相对优势（无需 critic）；PPO 式 clip 目标，可加 KL 惩罚防偏离 ref。

**公式**：

$$\hat{A}_i=\frac{r_i-\mathrm{mean}(r_{1:G})}{\mathrm{std}(r_{1:G})},\quad \rho=\frac{\pi_\theta}{\pi_{old}},\quad \mathcal{L}=-\mathbb{E}\left[\min(\rho\hat{A},\mathrm{clip}(\rho,1-\varepsilon,1+\varepsilon)\hat{A})\right]+\beta D_{KL}$$

```python
class Solution:
    def grpoLoss(self, B: int, G: int, L: int, beta: float, eps: float, old_logp: List[List[List[float]]], new_logp: List[List[List[float]]], rewards: List[List[float]], ref_logp: List[List[List[float]]] = None) -> str:
        # old/new/ref_logp: (B, G, L) token 级；rewards: (B, G)
        old = torch.tensor(old_logp, dtype=torch.float64)
        new = torch.tensor(new_logp, dtype=torch.float64)
        r = torch.tensor(rewards, dtype=torch.float64)
        adv = (r - r.mean(-1, keepdim=True)) / (r.std(-1, keepdim=True) + 1e-8)   # 组内归一化
        adv = adv.unsqueeze(-1)
        ratio = (new - old).exp()
        loss = -torch.min(ratio * adv, ratio.clamp(1 - eps, 1 + eps) * adv).mean()
        if beta > 0 and ref_logp is not None:
            t = torch.tensor(ref_logp, dtype=torch.float64) - new
            loss = loss + beta * (t.exp() - t - 1).mean()              # k3 估计 KL
        return f"{loss:.4f}"
```
