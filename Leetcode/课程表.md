## 207. Course Schedule

[LeetCode 207](https://leetcode.com/problems/course-schedule/)

判断有向图是否有环（能否完成所有课程）。

```python
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = defaultdict(list)
        indegree = [0] * numCourses
        for cur, pre in prerequisites:
            indegree[cur] += 1
            graph[pre].append(cur)

        q = deque()
        for i in range(numCourses):
            if indegree[i] == 0:
                q.append(i)

        count = 0
        while q:
            c = q.popleft()
            count += 1
            for nc in graph[c]:
                indegree[nc] -= 1
                if indegree[nc] == 0:
                    q.append(nc)

        return count == numCourses
```

## 210. Course Schedule II

[LeetCode 210](https://leetcode.com/problems/course-schedule-ii/)

返回一个合法的修课顺序（拓扑排序结果），不可能则返回空数组。

```python
class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        indegree = [0] * numCourses
        for cur, pre in prerequisites:
            indegree[cur] += 1
            graph[pre].append(cur)

        q = deque()
        for i in range(numCourses):
            if indegree[i] == 0:
                q.append(i)

        order = []
        while q:
            c = q.popleft()
            order.append(c)
            for nc in graph[c]:
                indegree[nc] -= 1
                if indegree[nc] == 0:
                    q.append(nc)

        return order if len(order) == numCourses else []
```

## DFS 解法（检测环）

用三色标记：0=未访问，1=访问中（在当前路径上），2=已完成。

```python
class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        graph = defaultdict(list)
        for cur, pre in prerequisites:
            graph[pre].append(cur)

        state = [0] * numCourses  # 0未访问 1访问中 2已完成

        def dfs(node):
            if state[node] == 1:
                return False  # 发现环
            if state[node] == 2:
                return True
            state[node] = 1
            for nei in graph[node]:
                if not dfs(nei):
                    return False
            state[node] = 2
            return True

        for i in range(numCourses):
            if not dfs(i):
                return False
        return True
```

## 知识点

### 拓扑排序（BFS / Kahn's Algorithm）

核心思路：不断移除入度为0的节点，如果最终所有节点都被移除，则无环。

```
建图 + 统计入度 → 入度为0的入队 → 出队时削减邻居入度 → 邻居入度归零则入队
```

时间 O(V+E)，空间 O(V+E)。

### 队列操作

详见 [[数据结构操作速记#3. Queue（队列）]]

```python
from collections import deque

q = deque()
q.append(x)      # 入队（右端）
x = q.popleft()  # 出队（左端）
len(q)           # 队列长度
```

### BFS vs DFS 选择

| 场景 | 推荐 |
|------|------|
| 判断是否有环 / 能否完成 | 两者皆可 |
| 需要输出拓扑序 | BFS（Kahn）更直观 |
| 需要检测环的具体路径 | DFS（记录递归路径） |

### 易错点

- `prerequisites[i] = [cur, pre]`：pre → cur 是有向边，别建反
- BFS 中不需要按层遍历（`for i in range(len(q))`），逐个出队即可
- DFS 中 `state[node] == 2` 的剪枝不能省，否则超时
