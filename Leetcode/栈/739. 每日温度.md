# 739. 每日温度

[LeetCode 739](https://leetcode.com/problems/daily-temperatures/) · 中等

相关：[[LeetCode 刷题汇总]] | [[数据结构操作速记]]

## 题意

给定每日温度数组，对每一天求「之后第一个更高温度出现在几天后」，没有则为 0。

## 思路

典型**单调递减栈**：栈里存下标，栈内对应温度从栈底到栈顶递减。当前元素比栈顶大时，说明栈顶那天等到了更高温度，弹出并结算天数差。

```python
class Solution:
    def dailyTemperatures(self, temperatures: List[int]) -> List[int]:
        n = len(temperatures)
        ans = [0] * n
        stack = []  # 存下标，对应温度单调递减

        for i, t in enumerate(temperatures):
            while stack and temperatures[stack[-1]] < t:
                j = stack.pop()
                ans[j] = i - j
            stack.append(i)

        return ans
```

时间 O(n)（每个下标进栈出栈各一次），空间 O(n)。

## 知识点：单调栈

用于求「下一个更大 / 更小元素」这一类问题。

```
遍历元素 → while 栈顶不满足单调性: 弹出并结算 → 当前元素入栈
```

| 目标 | 栈内单调性 | 弹出条件 |
|------|------------|----------|
| 下一个更大元素 | 递减 | 栈顶 < 当前 |
| 下一个更小元素 | 递增 | 栈顶 > 当前 |

存**下标**而不是值，才能算出「隔了几天 / 几个位置」。栈操作详见 [[数据结构操作速记#2. Stack（栈）]]。

## 易错点

- `while` 不能写成 `if`，一个新元素可能连续结算多个栈顶
- 访问 `stack[-1]` 前必须 `if stack`，否则空栈报 IndexError
- 栈里存的是下标，比较时要 `temperatures[stack[-1]]` 取值，别直接比下标
