# 394. 字符串解码

[LeetCode 394](https://leetcode.com/problems/decode-string/) · 中等

相关：[[LeetCode 刷题汇总]] | [[数据结构操作速记]]

## 题意

解码形如 `k[encoded_string]` 的字符串，可嵌套。例：`3[a2[c]]` → `accaccacc`。

## 思路

嵌套结构 → 栈。用两个栈分别保存「外层的重复次数」和「外层已拼好的字符串」：

- 遇 `[`：把当前 `num` 和 `cur` 压栈，然后清空，进入内层
- 遇 `]`：内层结束，`cur = 外层字符串 + cur * k`

```python
class Solution:
    def decodeString(self, s: str) -> str:
        num_stack = []
        str_stack = []
        cur = ""
        num = 0

        for ch in s:
            if ch.isdigit():
                num = num * 10 + int(ch)   # 多位数字
            elif ch == '[':
                num_stack.append(num)
                str_stack.append(cur)
                num = 0
                cur = ""
            elif ch == ']':
                k = num_stack.pop()
                cur = str_stack.pop() + cur * k
            else:
                cur += ch

        return cur
```

时间 O(输出长度)，空间 O(嵌套深度)。

## 图解 `3[a2[c]]`

```
读到 3        num=3
读到 [        num_stack=[3]  str_stack=[""]   num=0 cur=""
读到 a        cur="a"
读到 2        num=2
读到 [        num_stack=[3,2] str_stack=["","a"] num=0 cur=""
读到 c        cur="c"
读到 ]        k=2 → cur = "a" + "c"*2 = "acc"
读到 ]        k=3 → cur = ""  + "acc"*3 = "accaccacc"
```

## 易错点

- 数字可能是多位，必须 `num = num * 10 + int(ch)` 累积，不能直接 `int(ch)`
- 遇 `[` 时要把 `num` 和 `cur` **一起**入栈并**同时清零/清空**，否则内层会污染外层
- 遇 `]` 时是 `外层 + cur * k`，顺序别反成 `cur * k + 外层`
- 最终答案是 `cur` 而不是栈里的东西（题目保证括号合法，栈最后为空）
