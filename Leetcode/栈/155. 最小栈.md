# 155. 最小栈

[LeetCode 155](https://leetcode.com/problems/min-stack/) · 中等

相关：[[LeetCode 刷题汇总]] | [[数据结构操作速记]]

## 题意

设计一个栈，支持 `push / pop / top / getMin`，且**全部为 O(1)**。

## 思路

`getMin` 要 O(1)，就不能遍历求最小。用**辅助栈**与主栈同步增删，`min_stack[i]` 保存「主栈前 i+1 个元素的最小值」。

```python
class MinStack:
    def __init__(self):
        self.stack = []
        self.min_stack = []   # min_stack[i] = stack[:i+1] 的最小值

    def push(self, val: int) -> None:
        self.stack.append(val)
        if not self.min_stack:
            self.min_stack.append(val)
        else:
            self.min_stack.append(min(val, self.min_stack[-1]))

    def pop(self) -> None:
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```

所有操作 O(1)，空间 O(n)。

## 优化写法（省空间）

只在「新值 ≤ 当前最小」时才入辅助栈，pop 时只有「弹出值 == 栈顶最小」才同步弹出。

```python
def push(self, val):
    self.stack.append(val)
    if not self.min_stack or val <= self.min_stack[-1]:
        self.min_stack.append(val)

def pop(self):
    if self.stack.pop() == self.min_stack[-1]:
        self.min_stack.pop()
```

## 易错点

- 基础写法里辅助栈必须与主栈**同步 pop**，少 pop 一次 getMin 就永久失效
- 优化写法的入栈条件必须是 `<=` 而不是 `<`。若为 `<`，压入两个相同最小值时只记一次，弹出第一个后 getMin 就错了
- `push` 时辅助栈为空要特判，否则 `min_stack[-1]` 报 IndexError
- 别用「只存一个 min 变量」的做法——pop 掉最小值后无法恢复上一个最小值
