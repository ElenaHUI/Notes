# 210. 课程表 II

[LeetCode 210](https://leetcode.com/problems/course-schedule-ii/) · 中等

相关：[[LeetCode 刷题汇总]] | [[207. 课程表]] | [[数据结构操作速记]]

## 题意

返回一个合法的修课顺序（拓扑排序结果），不可能则返回空数组。

## 思路

和 [[207. 课程表]] 的 BFS 完全一致，只是把「计数」换成「记录出队顺序」，最后检查长度是否等于节点数。

```python
class Solution:
    def findOrder(self, numCourses: int, prerequisites: List[List[int]]) -> List[int]:
        graph = defaultdict(list)
        indegree = [0] * numCourses
        for cur, pre in prerequisites:
            indegree[cur] += 1
            graph[pre].append(cur)

        q = deque()
        for i in range(numCourses):
            if indegree[i] == 0:
                q.append(i)

        order = []
        while q:
            c = q.popleft()
            order.append(c)
            for nc in graph[c]:
                indegree[nc] -= 1
                if indegree[nc] == 0:
                    q.append(nc)

        return order if len(order) == numCourses else []
```

时间 O(V+E)，空间 O(V+E)。

## 易错点

- 有环时必须返回 `[]`，不能返回残缺的 `order`，所以结尾一定要判 `len(order) == numCourses`
- 答案不唯一，判题接受任意合法拓扑序
- 需要输出拓扑序时用 BFS（Kahn）比 DFS 直观；DFS 版本需要在回溯时**逆序**收集结果
