# 22. 括号生成

[LeetCode 22](https://leetcode.com/problems/generate-parentheses/) · 中等

相关：[[LeetCode 刷题汇总]] | [[数据结构操作速记]]

## 题意

给定 n 对括号，生成所有**有效**的括号组合。

## 思路

不要「先生成全部再筛选」，而是在生成过程中就用剪枝保证有效性。两条规则：

1. 左括号还没用完（`left < n`）才能放 `(`
2. 右括号数量必须**严格小于**左括号数量（`right < left`）才能放 `)`

```python
class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        ans = []
        path = []

        def backtrack(left, right):
            if len(path) == 2 * n:
                ans.append("".join(path))
                return

            if left < n:              # 剪枝1：左括号没用完
                path.append('(')
                backtrack(left + 1, right)
                path.pop()            # 撤销

            if right < left:          # 剪枝2：右括号不能超过左括号
                path.append(')')
                backtrack(left, right + 1)
                path.pop()

        backtrack(0, 0)
        return ans
```

结果数为卡特兰数 $C_n = \frac{1}{n+1}\binom{2n}{n}$，时间复杂度 O(4^n / √n)。

## 决策树（n = 3 部分展开）

```
""
├─ "("
│  ├─ "(("
│  │  ├─ "((("  → "((()))"
│  │  └─ "(()"  → "(()())" / "(())()"
│  └─ "()"
│     └─ "()("  → "()(())" / "()()()"
└─ ")"  ✗ 被剪枝2直接砍掉
```

## 知识点：回溯模板

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        收集结果
        return
    for 选择 in 选择列表:
        if 不合法: continue      # 剪枝
        做选择                    # path.append(x)
        backtrack(...)           # 递归
        撤销选择                  # path.pop()
```

三要素：**路径**（已做的选择）、**选择列表**（当前可做的选择）、**结束条件**。

剪枝 vs 事后过滤：

| 做法 | 复杂度 | 说明 |
|------|--------|------|
| 生成所有 2^(2n) 串再验证 | O(2^(2n) · n) | 能过但浪费 |
| 边生成边剪枝 | O(4^n / √n) | 只走有效分支 |

## 易错点

- 忘记 `path.pop()` 撤销选择，导致路径被污染
- 收集结果时直接 `ans.append(path)`：path 是可变对象，后续修改会影响已收集的结果，必须 `"".join(path)` 或 `path[:]` 做拷贝
- 剪枝2 写成 `right < n` 是错的，会生成 `)(` 这类非法串，必须是 `right < left`
- 结束条件用 `len(path) == 2 * n`，只判断 `left == n` 会漏掉右括号未补齐的情况
