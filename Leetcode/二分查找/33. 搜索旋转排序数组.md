# 33. 搜索旋转排序数组

[LeetCode 33](https://leetcode.com/problems/search-in-rotated-sorted-array/) · 中等

相关：[[LeetCode 刷题汇总]] | [[153. 寻找旋转排序数组中的最小值]]

## 题意

在旋转后的升序数组（无重复）中查找 target，返回下标，不存在返回 -1，要求 O(log n)。

## 思路

核心性质：**从中点切开，必有一半是完全有序的**。先判断哪一半有序，再看 target 是否落在这个有序区间内，从而决定往哪边收缩。

```
[4,5,6,7,0,1,2]
 └─ 左半有序 ─┘        mid=7 时左半 [4,5,6,7] 有序
[6,7,0,1,2,4,5]
       └─ 右半有序 ─┘   mid=1 时右半 [1,2,4,5] 有序
```

判断依据：`nums[left] <= nums[mid]` 成立则左半有序，否则右半有序。

```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left, right = 0, len(nums) - 1

        while left <= right:
            mid = (left + right) // 2
            if nums[mid] == target:
                return mid

            if nums[left] <= nums[mid]:          # 左半 [left, mid] 有序
                if nums[left] <= target < nums[mid]:
                    right = mid - 1
                else:
                    left = mid + 1
            else:                                 # 右半 [mid, right] 有序
                if nums[mid] < target <= nums[right]:
                    left = mid + 1
                else:
                    right = mid - 1

        return -1
```

时间 O(log n)，空间 O(1)。

## 另一种解法

先用 [[153. 寻找旋转排序数组中的最小值]] 的方法找到旋转点，再在对应的有序段里做普通二分。两次 O(log n)，思路更直白但代码更长。

## 易错点

- `nums[left] <= nums[mid]` 的**等号不能丢**：区间只剩两个元素时 `left == mid`，没有等号会误判成右半有序
- 判断 target 是否在有序区间时，边界开闭要和「mid 已被排除」对应：左半用 `nums[left] <= target < nums[mid]`，右半用 `nums[mid] < target <= nums[right]`
- 这题是「找确定值」，用 `left <= right` + `mid ± 1` 模板，和 153 的模板不同，别混用
- 有重复元素时是 81 题，需要在 `nums[left] == nums[mid]` 时 `left += 1` 跳过

## 两种二分模板对比

| 模板 | 循环条件 | 收缩方式 | 适用 |
|------|----------|----------|------|
| 找确定值 | `left <= right` | `left = mid+1` / `right = mid-1` | 33、74，找到即返回 |
| 找边界/极值 | `left < right` | `left = mid+1` / `right = mid` | 153，退出时 `left == right` 即答案 |
