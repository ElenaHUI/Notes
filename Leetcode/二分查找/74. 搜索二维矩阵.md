# 74. 搜索二维矩阵

[LeetCode 74](https://leetcode.com/problems/search-a-2d-matrix/) · 中等

相关：[[LeetCode 刷题汇总]] | [[33. 搜索旋转排序数组]]

## 题意

矩阵每行升序，且每行第一个数大于上一行最后一个数。判断 target 是否存在，要求 O(log(mn))。

## 思路

题目条件意味着：**整个矩阵按行展开就是一个升序数组**。所以直接在 `[0, m*n-1]` 上做普通二分，用除模还原二维坐标。

```
matrix = [[1, 3, 5],        展开 → [1,3,5,7,10,11,23,30,34]
          [7,10,11],
          [23,30,34]]       下标 k → 行 k//n，列 k%n
```

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        left, right = 0, m * n - 1

        while left <= right:
            mid = (left + right) // 2
            val = matrix[mid // n][mid % n]     # 注意都是除以列数 n
            if val == target:
                return True
            elif val < target:
                left = mid + 1
            else:
                right = mid - 1

        return False
```

时间 O(log(mn))，空间 O(1)。

## 解法二：从右上角走（O(m+n)）

从右上角出发，比 target 大就左移一列，小就下移一行。虽然更慢，但**不依赖「行间有序」这个条件**，因此可以直接推广到 240 题（每行每列有序，但行间无关系）。

```python
class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        i, j = 0, len(matrix[0]) - 1
        while i < len(matrix) and j >= 0:
            if matrix[i][j] == target:
                return True
            elif matrix[i][j] > target:
                j -= 1      # 当前列都太大，左移
            else:
                i += 1      # 当前行都太小，下移
        return False
```

## 易错点

- `mid // n` 和 `mid % n` 都用**列数 n**，写成 m 是最常见的错
- `right` 初值是 `m * n - 1`，不是 `m * n`
- 解法二只能从右上角或左下角出发，从左上/右下角开始无法确定唯一的移动方向
