## 总览

| 数据结构                        | Python声明                                             | 添加元素                           | 删除元素                      | 备注          |
| --------------------------- | ---------------------------------------------------- | ------------------------------ | ------------------------- | ----------- |
| **数组 Array / List**         | `a=[]`                                               | `a.append(x)`                  | `a.pop()` / `a.remove(x)` | Python中最常用  |
| **栈 Stack**                 | `stack=[]`                                           | `stack.append(x)`              | `stack.pop()`             | 后进先出 LIFO   |
| **队列 Queue**                | `from collections import deque``q=deque()`           | `q.append(x)`                  | `q.popleft()`             | 先进先出 FIFO   |
| **双端队列 Deque**              | `q=deque()`                                          | `q.append(x)``q.appendleft(x)` | `q.pop()``q.popleft()`    | 两端操作        |
| **链表 Linked List**          | 自定义Node                                              | `node.next=newNode`            | 修改指针                      | Python无内置链表 |
| **哈希表 HashMap / Dict**      | `d={}`                                               | `d[key]=value`                 | `del d[key]`              | 键值映射        |
| **哈希集合 HashSet**            | `s=set()`                                            | `s.add(x)`                     | `s.remove(x)`             | 去重          |
| **堆 Heap / Priority Queue** | `heap=[]`                                            | `heapq.heappush(heap,x)`       | `heapq.heappop(heap)`     | 默认小根堆       |
| **优先队列 PriorityQueue**      | `from queue import PriorityQueue``q=PriorityQueue()` | `q.put(x)`                     | `q.get()`                 | 多线程安全       |
| **二叉树 Binary Tree**         | `TreeNode()`                                         | `node.left=x`                  | `node.left=None`          | 自定义结构       |
| **图 Graph（邻接表）**            | `graph={}` 或 `graph=[[]]`                            | `graph[u].append(v)`           | `remove(v)`               | DFS/BFS常用   |
# 1. List（数组）

声明：

```
nums = []
```

添加：

```
nums.append(1)
nums.append(2)
```

结果：

```
[1,2]
```

删除：

```
nums.pop()
```

删除最后一个：

```
[1]
```

删除指定值：

```
nums.remove(1)
```

---

# 2. Stack（栈）

Python直接用 list：

```
stack=[]
```

### 入栈

```
stack.append(x)
```

### 出栈

```
stack.pop()
```

例：

```
stack=[]

stack.append(1)
stack.append(2)
stack.append(3)

print(stack.pop())
```

输出：

```
3
```

应用：

- 括号匹配
- 单调栈
- DFS递归模拟

---

# 3. Queue（队列）

使用 deque：

```
from collections import deque

q=deque()
```

### 入队

```
q.append(x)
```

### 出队

```
q.popleft()
```

例：

```
q.append(1)
q.append(2)

q.popleft()
```

结果：

```
2
```

应用：

- BFS
- 层序遍历
- 拓扑排序

---

# 4. HashMap（字典）

```
mp={}

mp["a"]=10

del mp["a"]

```

mp.get("a")

# 6. Heap（堆）

Python：

```
import heapq

heap=[]
```

默认：

> 小根堆

---

添加：

```
heapq.heappush(heap,x)
```

删除最小值：

```
heapq.heappop(heap)
```

例：

```
heap=[]

heapq.heappush(heap,5)
heapq.heappush(heap,2)
heapq.heappush(heap,8)

print(heapq.heappop(heap))
```

输出：

```
2
```

应用：

- Top K问题
- Dijkstra
- 优先队列

---

# 7. 链表 Linked List

Python没有内置：

需要自己定义：

```
class ListNode:
    def __init__(self,val):
        self.val=val
        self.next=None
```

创建：

```
a=ListNode(1)
b=ListNode(2)

a.next=b
```

结构：

```
1 -> 2 -> None
```

删除：

例如删除b：

```
a.next=b.next
```

graph=[

# 9. 二叉树

节点：

```
class TreeNode:

    def __init__(self,val):
        self.val=val
        self.left=None
        self.right=None
```

创建：

```
root=TreeNode(1)

root.left=TreeNode(2)
root.right=TreeNode(3)
```

结构：

```
      1
    /   \
   2     3
```
