## Qwen 系列架构演变

Qwen 系列是阿里通义实验室推出的大语言模型家族，从2023年至今经历了多代迭代，在架构、数据、推理能力上逐步演进。以下选取最具代表性的几代进行梳理。

---

## 一、Qwen（初代）

**Qwen Technical Report**

发表时间：2023年9月

Qwen 初代是通义千问的奠基之作，目标是在中英双语场景下构建一个与 GPT-3.5 级别相当的开源基座模型。它在架构上遵循了当时主流的 Decoder-only Transformer 范式，但在细节设计上做了多项针对中文和多语言的优化。

### 1. 架构

Qwen 初代提供 1.8B、7B、14B、72B 四种规模的 Dense 模型。核心架构特征包括：

- **注意力机制**：采用 Multi-Head Attention（MHA），并在 QKV 投影中保留了 bias 项（这一点与后来 Llama 系列去掉 bias 的做法不同）。
- **激活函数**：使用 SwiGLU 作为 FFN 的激活函数，相比传统 ReLU/GELU 能更好地捕捉特征交互。
- **位置编码**：采用 RoPE（旋转位置编码），原生支持 8192 token 上下文长度，可通过 NTK-aware 插值扩展到更长序列。
- **词表**：约 151,936 个 token 的超大词表，对中文和 CJK 字符做了专门优化，使得中文文本的 tokenization 效率显著高于 Llama 等纯英文模型。
- **Embedding 不共享**：输入 embedding 和输出 lm_head 使用独立的参数矩阵（untied），有助于模型表达能力的解耦。

预训练数据约 3 万亿 token，覆盖文本、代码、数学等多领域。

### 2. 突出贡献

- **中文开源标杆**：在同期开源模型中，中文能力显著领先 Llama/Llama-2，成为中文社区广泛采用的基座。
- **大词表设计**：证明了大词表对多语言（尤其 CJK）tokenization 效率的提升作用，影响了后续众多模型的设计。
- **代码与数学专项**：同步发布了 Code-Qwen 和 Math-Qwen 变体，展示了领域专精微调的可行性。

## 二、Qwen1.5

发表时间：2024年2月

Qwen1.5 是初代 Qwen 的渐进式改进版本，目标不是架构颠覆，而是**扩大规模覆盖、完善工具链和生态**。

### 1. 架构

架构上基本沿用 Qwen 初代的设计（MHA + SwiGLU + RoPE），主要变化在于：

- **模型规模全覆盖**：一次性发布 0.5B、1.8B、4B、7B、14B、32B、72B、110B 共 8 个尺寸的 Dense 模型，以及一个 MoE 变体，覆盖了从手机端到数据中心的全场景部署需求。
- **上下文扩展**：全系列统一支持 32,768 token 的上下文长度（相比初代的 8K 是大幅提升）。
- **多语言增强**：基础模型评估覆盖 12 种语言（欧洲、东亚、东南亚），中文之外的多语言能力得到系统性加强。
- **对齐改进**：对话版本引入 DPO 和 PPO 两种对齐方法，遵循人类偏好的能力显著提升。
- **生态整合**：代码直接合并入 Hugging Face Transformers，不再需要外部脚本，降低了使用门槛。

### 2. 突出贡献

- **MoE 初探**：首次引入 MoE 变体，为后续 Qwen2 的 MoE 架构积累了经验。
- **全尺寸矩阵**：一次性提供从 0.5B 到 110B 的完整尺寸选择，在同期的开源模型家族中极为罕见。
- **生态标准化**：与 HuggingFace 原生集成，确立了 Qwen 系列在开源社区的易用性标杆。

## 三、Qwen2

**Qwen2 Technical Report**

发表时间：2024年6月

Qwen2 是一次架构层面的重大升级，标志着 Qwen 系列从"跟随主流"走向"主动设计"。

### 1. 架构

Qwen2 提供 0.5B、1.5B、7B、72B 四种 Dense 模型，以及一个 57B-A14B 的 MoE 变体（总参数 57B，每个 token 激活 14B）。核心架构变化：

#### a. Grouped Query Attention（GQA）

Qwen2 将初代的 MHA 全面替换为 **Grouped Query Attention（GQA）**。GQA 的核心思想是让多个 Query 头共享同一组 Key 和 Value，从而大幅减少 KV Cache 的显存占用。与 Multi-Query Attention（MQA，所有头共享一组 KV）不同，GQA 在减少 KV 存储的同时保留了多组 KV 的表达能力，在推理效率和模型质量之间取得了更好的平衡。这一改动直接提升了推理吞吐量，尤其在长序列和高并发场景下效果显著。

#### b. 长上下文与 YARN

原生上下文扩展到 32,768 token，并通过 **YARN（Yet Another RoPE extensioN）** 机制外推到 131,072 token。YARN 的核心是对 RoPE 的注意力权重进行重新缩放，使得模型在处理远超训练长度的序列时，位置编码的插值更加平滑，避免了 NTK-aware 方法中高频分量失真的问题。同时将 RoPE 基频从 10,000 提升到 1,000,000，进一步增强了长序列的位置区分能力。

#### c. 其它改进

- **去除 QKV bias**：相比初代保留的 bias 项，Qwen2 去掉了注意力投影中的 bias，简化了计算图。
- **训练数据翻倍**：预训练数据从 3T 扩展到 **7T+ token**，数学和代码语料大幅增补。
- **约 30 种语言**：多语言覆盖从 12 种扩展到约 30 种。

### 2. 突出贡献

- **GQA 全面落地**：是同期开源模型中较早全面采用 GQA 的系列之一，验证了 GQA 在开源模型中的可行性。
- **MoE 正式引入**：57B-A14B 的 MoE 变体标志着 Qwen 正式进入稀疏架构赛道，与 Mixtral 等模型直接竞争。
- **YARN 长上下文**：128K 的上下文支持能力在同期开源模型中处于领先位置。

## 四、Qwen2.5

**Qwen2.5 Technical Report**

发表时间：2024年9月（最终版 2025年1月）

Qwen2.5 是一次**数据和能力层面的飞跃**，架构上延续 Qwen2 的设计，但在训练规模、专项能力、推理效率上做了全面升级。

### 1. 架构

Dense 模型提供 0.5B、1.5B、3B、7B、14B、32B、72B 七种尺寸，API 版本提供 Turbo 和 Plus 两个 MoE 变体。架构延续 Qwen2 的 GQA + SwiGLU + RoPE 框架，主要升级集中在：

#### a. 数据规模爆发式增长

预训练数据从 Qwen2 的 7T token 直接扩展到 **18T token**，增幅超过 2.5 倍。后训练阶段使用了超过 **100 万条** SFT 样本，并结合离线和在线强化学习（Offline + Online RL）进行对齐。数据质量和多样性的提升是 Qwen2.5 性能跃升的最核心驱动力。

#### b. 推理效率优化

引入基于 **Minference** 的稀疏注意力机制，在推理阶段对注意力计算进行稀疏化加速，降低了长序列推理的计算开销。同时结合 **Dual Chunk Attention（DCA）**，将长序列分块处理，进一步提升了长上下文推理的效率。

#### c. 生成能力与结构化输出

最大生成 token 数从 Qwen2 的 2K 提升到 **8K**，Turbo 变体更支持高达 **100 万 token** 的上下文长度。同时增强了对结构化输入/输出的格式化能力（表格、JSON 等），使其在 Agent 和工具调用场景中更加实用。

#### d. 专项模型分化

同步发布了 Qwen2.5-Coder 和 Qwen2.5-Math 两个专精系列，分别在代码生成和数学推理上达到同期开源最优水平。72B 指令模型在多项基准上与 Llama-3-405B-Instruct 竞争。

### 2. 突出贡献

- **18T 数据规模**：证明了数据量对模型能力的决定性作用，成为开源社区中"数据为王"理念的代表性案例。
- **Minference 稀疏注意力**：为长序列推理的效率优化提供了实用方案。
- **全尺寸 + 全专项**：从 0.5B 到 72B 的完整矩阵 + Coder/Math 专精系列，构成了同期最完整的开源模型家族。

## 五、Qwen3

**Qwen3 Technical Report**

发表时间：2025年4月

Qwen3 是 Qwen 系列迄今最具架构创新的一代，核心贡献是将**思考模式（Thinking Mode）**内建到单一模型中，同时对 MoE 架构进行了深度优化。

### 1. 架构

Qwen3 同时提供 Dense 和 MoE 两类模型。Dense 包括 0.6B、1.7B、4B、8B、14B、32B 六种尺寸；MoE 包括 30B-A3B（总参数 30B，激活 3B）和旗舰 235B-A22B（总参数 235B，激活 22B）。

#### a. 统一思考模式（Thinking Mode）

这是 Qwen3 最核心的创新。传统做法是分别训练一个聊天模型和一个推理模型（如 OpenAI 的 GPT-4o 与 o1），用户需要在两者之间切换。Qwen3 将两种能力**统一在同一个模型中**：

- **Thinking Mode**：模型先进行多步链式推理（Chain-of-Thought），再输出最终答案，适用于数学、代码、逻辑等复杂推理任务。
- **Non-thinking Mode**：模型直接输出快速响应，适用于日常对话和简单查询。

两种模式通过 /think 和 /no_think 标志在 prompt 中动态切换，无需部署两套模型。更关键的是，Qwen3 引入了 **Thinking Budget 机制**：用户可以设定一个推理预算（如最大思考 token 数），模型在达到预算时自动触发 stop-thinking 指令，在推理质量和响应速度之间实现细粒度平衡。

#### b. MoE 架构精炼

Qwen3 的 MoE 设计相比 Qwen2 的 57B-A14B 做了重大调整：

- **无共享专家**：去掉了 Qwen2.5 中的共享专家设计（团队实验发现共享专家对推理优化的提升不足以抵消其带来的额外推理开销）。
- **细粒度专家分割**：128 个路由专家，每个 token 激活 8 个，专家粒度更细、专业化程度更高。
- **全局批次负载均衡损失（Global-batch Load Balancing Loss）**：替代传统的 per-token 负载均衡，在整个 batch 层面调控专家激活分布，避免某些专家被过度使用或闲置，促进更均衡的知识分配。

#### c. 注意力机制微调

- **QK-Norm**：在 Query 和 Key 上引入归一化，稳定注意力计算的数值范围，减少训练中的梯度异常。
- **去除 QKV bias**：延续 Qwen2 的无 bias 设计。
- 上下文方面，小尺寸 Dense 模型支持 32K，大尺寸 Dense 和 MoE 模型支持 **128K**。

#### d. 知识蒸馏驱动的小模型

小尺寸模型（如 0.6B、1.7B）并非独立从头训练，而是通过从旗舰模型蒸馏知识来构建，在极低参数量下仍保持较强的能力，显著降低了小模型的计算成本。

### 2. 突出贡献

- **统一思考模型**：首次在开源模型中将"快思考"和"慢思考"统一到单一模型中，并提供了 thinking budget 这一细粒度控制机制，影响了后续 DeepSeek、Kimi 等模型的思考模式设计。
- **MoE 去共享专家**：通过实验论证了在高专家数场景下，共享专家的边际收益递减，为 MoE 架构设计提供了新的参考方向。
- **119 种语言**：多语言覆盖从 30 种大幅扩展到 119 种语言和方言，成为多语言覆盖最广的开源模型之一。

## 六、Qwen3-Next（Qwen3.8-Flash-Next）

发表时间：2025年8月

Qwen3-Next 是面向下一代（Qwen4）的架构预览版本，核心目标是**极致的训练和推理效率**，在架构上引入了混合注意力机制，是 Qwen 系列迄今最具实验性质的一代。

### 1. 架构

当前发布的旗舰版本为 80B-A3B（总参数 80B，每个 token 仅激活 3B），是一个 MoE 模型。

#### a. Gated DeltaNet + Gated Attention 混合注意力

这是 Qwen3-Next 最大的架构突破。传统 Transformer 的每一层都使用 Full Attention（全注意力），其计算复杂度为 O(n²)，在长序列场景下计算成本极高。Qwen3-Next 将标准注意力层替换为两种注意力机制的混合：

- **Gated DeltaNet**：一种线性注意力变体，计算复杂度为 O(n)，擅长处理长上下文中的信息聚合，但在精细推理上不如全注意力。
- **Gated Attention**：标准的全注意力机制（O(n²)），擅长精确的多跳推理和细粒度信息检索。

两种机制以约 **3:1 的比例交错排列**（每 4 层中约 3 层使用 Gated DeltaNet，1 层使用 Gated Attention），使得模型在保持推理能力的同时，将整体注意力计算复杂度从 O(n²) 降低到接近 O(n)，原生支持 65K+ 的上下文长度。

#### b. Multi-Token Prediction（MTP）

Qwen3-Next 引入了多 Token 预测机制：在训练阶段，模型不仅预测下一个 token，还同时预测未来的多个 token，提升了训练效率；在推理阶段，模型可以每步解码多个 token，结合投机解码（Speculative Decoding）显著提升生成速度。

#### c. 极致稀疏 MoE

专家激活比达到约 **1:50**（80B 总参数仅激活 3B），是 Qwen 系列中稀疏度最高的模型。同时重新引入了共享专家（此前在 Qwen3 中被去除），说明团队在不同架构方向上持续探索。

### 2. 突出贡献

- **混合注意力落地**：首次在大规模语言模型中验证了 Gated DeltaNet + Full Attention 混合架构的可行性，为突破 O(n²) 注意力瓶颈提供了实际方案。
- **MTP 训练-推理双加速**：将多 token 预测同时应用于训练和推理，在效率提升上形成了完整的闭环。
- **架构预览**：作为 Qwen4 的"试验田"，为下一代模型的架构选型提供了关键的实验数据。
